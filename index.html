Политика конфиденциальности

Настоящая Политика конфиденциальности описывает, как студия веб-дизайна eanka.ru (далее — «Оператор») собирает, использует и защищает персональные данные пользователей сайта eanka.ru.

1. Общие положения

Использование сайта eanka.ru означает согласие пользователя с настоящей Политикой конфиденциальности и условиями обработки персональных данных.

2. Сбор персональных данных

Оператор может собирать следующие персональные данные:

  • Имя и фамилия
  • Адрес электронной почты
  • Номер телефона
  • Информация о проекте

3. Цели обработки персональных данных

Персональные данные обрабатываются для:

  • Связи с пользователем для обсуждения проекта
  • Предоставления услуг по созданию сайтов
  • Отправки коммерческих предложений

4. Защита персональных данных

Оператор принимает необходимые организационные и технические меры для защиты персональных данных от несанкционированного доступа, изменения, раскрытия или уничтожения.

5. Права пользователя

Пользователь имеет право на получение информации об обработке своих персональных данных, их уточнение, блокирование или уничтожение.

6. Контактная информация

По всем вопросам, связанным с обработкой персональных данных, обращайтесь: eanka-info@mail.ru
